Le bandeau système affiche `operationnel`, l’ordre `Gemini → Groq → OpenRouter → Mock` et `memoire: supabase`. Le panneau Supabase affiche `Backend memoire actuel : supabase. Persistance serveur active.`.

Le wizard comporte cinq étapes visibles : Supabase, IA, Facebook/Instagram, TikTok et WhatsApp. Les connecteurs Facebook, Instagram, TikTok, WhatsApp et YouTube affichent `non connecte`; aucune connexion fictive n’est présentée. Les clés IA facultatives non configurées sont indiquées honnêtement comme `cle non configuree`, tandis que le fournisseur Mock reste disponible.

Le champ de clé API est de type mot de passe et aucune valeur secrète n’est affichée dans la page extraite.
